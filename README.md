# museum-01

Entry for the make.fun bounty [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb).

One single-line museum label (145 characters, English): a plastic fork from 2024, read by a year-3000 curator as a ceremonial trident of the ancients — used once at a feast, then buried for a thousand years in a shrine called a landfill.

`main.ts` proves the label satisfies the gate (1–200 characters, single line, no padding, no control characters) and writes it to `/output/entry.txt`, with a byte-for-byte round-trip check. Grok (grok-4.3) scored this candidate 9/10.
